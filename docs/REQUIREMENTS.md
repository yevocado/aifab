# 러닝 인증샷 디자인 — 요구사항

## 1. 개요

러닝 사진과 운동 기록을 보내면, Claude가 그날 런의 종류와 기록에 맞춰 매번 다른 인스타 스토리용 인증샷을 디자인한다.

- **목적:** 고정 템플릿에 숫자만 바꾸는 방식이 아니라, 런 종류·사진·기록에 맞춘 한 장짜리 디자인을 빠르게 얻는다.
- **사용자:** 이예린 (하프마라톤 준비 중, Apple Watch 사용)
- **범위:** 입력 해석 → 런 종류 판별 → 디자인 생성 → 캔버스에 아트보드 추가. 인스타 업로드는 범위 밖.

### 사용 흐름

1. 사용자가 원본 러닝 사진 + 운동 앱 캡처를 보낸다.
2. Claude가 캡처에서 기록을 읽고, 캘린더 훈련 일정과 날짜를 맞춰 런 종류를 정한다.
3. Claude가 런 종류별 컨셉으로 디자인을 만들어 "러닝 인증샷 템플릿" 캔버스에 새 아트보드로 추가한다.
4. 사용자가 캔버스에서 글자·색을 고치고 이미지로 내보낸다.

## 2. 입력 요구사항

사진 1장과 기록 캡처 1장 이상이 있어야 제작을 시작한다.

| ID | 입력 | 필수 | 설명 |
|---|---|---|---|
| IN-01 | 러닝 사진 | 필수 | 글자·기록이 없는 원본. 세로 권장 |
| IN-02 | 운동 기록 캡처 | 필수 | Apple Watch 운동 앱, Strava, 가민 등. 여러 장 가능 |
| IN-03 | 경로 지도 캡처 | 선택 | 경로 라인 그래픽에 사용 |
| IN-04 | 구간(스플릿)·심박 존 캡처 | 선택 | 인터벌·템포 그래프에 사용 |
| IN-05 | 런 종류 한마디 | 선택 | 플랜에 없던 런일 때만 |
| IN-06 | 한 줄 메모 | 선택 | "비 왔음", "최고 기록" 등 디자인에 넣을 문구 |

캡처에서 읽을 항목: 날짜, 시작·종료 시각, 거리(km), 운동 시간, 평균 페이스, 평균·최대 심박, 케이던스, 고도, 구간별 페이스, 경로.

## 3. 기능 요구사항

| ID | 기능 | 내용 |
|---|---|---|
| FR-01 | 기록 추출 | 캡처에서 2장의 항목을 읽는다. 보이는 값만 쓰고 추정·계산값을 만들지 않는다 |
| FR-02 | 런 종류 판별 | 캘린더에서 같은 날짜의 🏃 일정을 찾아 종류를 정한다. 없으면 기록으로 추정하고 디자인 전에 한 줄로 알린다 |
| FR-03 | 사진 처리 | 사진에 이미 글자가 박혀 있으면 글자 없는 부분만 잘라 쓴다 |
| FR-04 | 컨셉 선정 | 런 종류 + 사진 분위기(색, 배경, 시간대)로 디자인 컨셉과 이름을 정한다. 예: 다리 케이블 사진 → "Night Cable" |
| FR-05 | 데이터 그래픽 | 경로가 있으면 경로 라인, 스플릿이 있으면 구간 막대, 심박 존이 있으면 존 띠를 그린다 |
| FR-06 | 산출물 | "러닝 인증샷 템플릿" 캔버스에 RunMMDD 아트보드로 추가. 기존 아트보드 아래 줄에 날짜순 배치 |
| FR-07 | 수정 요청 | "색 바꿔", "숫자 더 크게" 같은 요청은 해당 아트보드만 고친다 |

## 4. 디자인 요구사항

규격은 인스타 스토리 1080×1920px로 고정하고, 컨셉은 런 종류에 따라 달리한다.

| 런 종류 | 핵심 그래픽 | 분위기 |
|---|---|---|
| 롱런 | 경로 모양을 굵은 라인으로, 디자인 중심에 배치 | 거리감, 여유 |
| 인터벌 | 빠른 구간 페이스 막대, 구간 간 균일함 강조 | 리듬, 강렬함 |
| 템포런 | 심박 존 색 띠, 템포 구간 하이라이트 | 속도감 |
| 회복런 / Zone 2 | 낮게 유지된 심박 | 차분함 |
| 레이스 / 기록 측정 | 목표 대비 기록, 기록증 느낌 | 기념비적 |

### 공통 규칙

- 거리를 가장 크게, 그다음 시간·페이스·심박 순.
- 숫자는 Anton, 한글은 Noto Sans KR. 포인트 컬러는 사진에서 뚜 색 1개 + 보조 1개.
- 포인트 컬러는 캔버스 Tweaks에서 바꿀 수 있게 한다.
- 글자는 사진 위에서도 명암비 4.5:1 이상.

### 금지

- 이모지, 가짜 상태바, 다른 브랜드 로고 (Strava·Apple 등).
- 직전 디자인과 같은 레이아웃 반복.
