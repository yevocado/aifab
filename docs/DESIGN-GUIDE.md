# 디자인 가이드 — 레퍼런스 분석과 매번 다르게 만드는 법

사진과 런 종류를 보고 Claude가 직접 판단해 디자인한다. 이 문서는 그 판단 기준이다.
요구사항 원문: [`REQUIREMENTS.md`](REQUIREMENTS.md)

## 1. 레퍼런스 분석 (2026-11 기준)

| 레퍼런스 | 방식 | 잘한 점 | 아쉬운 점 |
|---|---|---|---|
| Strava Stats Sticker (2025 봄~) | 투명 PNG 스티커: 거리·고도·시간 + 얇은 경로 라인 + 로고 | 사진을 가리지 않음, 깔끔 | 누구나 같은 모양, 숫자 수정 불가 |
| FitnessOverlays / StatShot / PicStat | 레이아웃·색·항목을 골라 사진에 얹음, 경로 색·두께 조절 | 커스터마이즈 자유 | 결국 템플릿 몇 개 안에서 돎 |
| 런클립 (국내) | 거리·페이스·코스 지도를 블록처럼 배치 | 모듈형, 배치 자유 | 블록이 많아지면 산만 |
| 러니메이트 + 캡컷 | 숫자가 올라가는 기록 영상을 '어둡게' 합성 | 움직임, 화제성 | 제작이 번거로움, 정지 이미지 아님 |
| Apple Watch 기본 공유 (사용자 11/13 캡처) | 날짜·거리·4개 지표가 사진 전체에 흩어짐 + 초록 경로선 | 정보 다 있음 | 사진 주인공(다리)과 경쟁, 위계 약함, 경로선이 사진을 가로지름 |

**공통 흐름**
1. **사진이 주인공.** 숫자는 사진의 빈 곳(하늘, 바닥, 어두운 면)에 모은다.
2. **숫자 하나만 거대하게.** 거리 1개를 압도적으로, 나머지는 작게 한 줄.
3. **얇은 경로 라인**이 사실상 표준 장식. 사진을 가로지르지 않고 독립 오브젝트로 둔다.
4. **포인트 컬러는 1개.** 러닝 패션과 같이 "감도"가 중요해짐 — 사진에서 뽑은 색.
5. 로고·이모지·앱 UI 흉내는 촌스러워지는 중.

**차별화 포인트 (이 프로젝트가 앱보다 나은 점)**
- 앱은 템플릿을 고르는 것, 여기선 **사진 구도에 맞춰** 레이아웃을 새로 짠다.
- 런 종류마다 **다른 데이터 그래픽**(경로 / 구간 막대 / 심박 띠)으로 그날의 훈련 의미를 보여준다.

## 2. 사진 읽는 법 (디자인 전 체크)

1. **빈 공간 찾기** — 하늘, 바닥, 벽, 어두운 물. 거리 숫자는 가장 넓은 빈 곳에.
2. **주인공 피하기** — 사람·다리·건물 같은 피사체는 글자로 덮지 않는다.
3. **선 따라가기** — 사진의 강한 선(케이블, 도로, 난간)이 있으면 레이아웃 축을 맞춘다.
4. **색 뽑기** — 가장 채도 높은 색 = 포인트, 그 보색 또는 밝은 중성색 = 보조.
5. **시간대** — 밤: 어두운 그라데이션 + 발광 색 / 낮: 밝은 글자 + 그림자 대신 반투명 바.

## 3. 레이아웃 라이브러리 (직전과 겹치지 않게 돌려 쓴다)

| 코드 | 이름 | 구성 | 잘 맞는 사진 |
|---|---|---|---|
| L1 | Sky Hero | 위쪽 빈 하늘에 거리 초대형, 아래 한 줄 지표 | 하늘 넓은 풍경 |
| L2 | Bottom Band | 사진은 그대로, 하단 1/3 그라데이션 위에 모든 숫자 | 피사체가 위·중앙 |
| L3 | Side Rail | 왼쪽 세로 레일에 숫자 세로 쌓기, 거리 세로쓰기 가능 | 피사체가 오른쪽 |
| L4 | Diagonal | 사진 속 사선(케이블·도로)을 따라 숫자 배치 | 강한 사선 구도 |
| L5 | Poster Frame | 위아래 단색 여백 + 가운데 사진 박스, 기록증 느낌 | 레이스, 기록 측정 |
| L6 | Data Center | 경로/그래프가 화면 중심, 사진은 어둡게 깔림 | 롱런, 사진이 평범할 때 |

## 4. 런 종류 × 기본 레이아웃 후보

| 런 종류 | 1순위 | 2순위 | 그래픽 |
|---|---|---|---|
| 롱런 | L6 | L1 | 굵은 경로 라인 |
| 인터벌 | L3 | L2 | 구간 페이스 막대 |
| 템포런 | L4 | L2 | 심박 존 띠 + 템포 구간 하이라이트 |
| 회복런 / Zone 2 | L1 | L2 | 낮게 깔린 심박 라인, 여백 많이 |
| 레이스 / 기록 측정 | L5 | L1 | 목표 대비 기록 |

직전 아트보드와 같은 코드가 나오면 다음 후보로 넘긴다.

## 5. 예시 — 11/13 사진 ("Night Cable")

- 사진: 밤, 마젠타 주탑 + 핑크·보라 케이블 사선, 위쪽 하늘이 넓게 비어 있음.
- 포인트 #E040C8 계열(마젠타), 보조 #FF6B6B 계열(케이블 핑크) — 실제 값은 사진에서 추출.
- 레이아웃: L4 Diagonal — 케이블 사선 각도에 맞춰 `8.06 KM`을 기울여 하늘에 배치, 하단에 47:10 · 5'51" · 176bpm 한 줄.
- 주의: 이 사진은 기록이 이미 박혀 있어 하늘과 다리 상단만 잘라 쓸 수 있다. 원본이 있으면 원본 사용.
